## Overview

5Digea helps couples plan their wedding in one place — they discover, compare and save vendors (venues, photographers, makeup artists, dresses, decor, cars…) and track their wedding plan, while vendors manage their profiles, services and reviews. Every listing is reviewed and approved by an admin before going live.

## ✨ Key Features

**For couples**
- Search, filter and compare vendors by category and location
- Favorites and a personal **wedding-plan** tracker
- Ratings and reviews

**For vendors**
- Vendor dashboard to manage profile, services and media
- Reviews management with **Excel export**
- Analytics charts

**For admins**
- Approval workflow for vendors and services
- Platform-wide dashboards and statistics

**Platform**
- 🌍 **Arabic (RTL) first** with full English support
- 🔐 Role-based access (couple / vendor / admin) with JWT authentication
- ⚡ Next.js App Router, server rendering and optimized self-hosted Arabic fonts
- 🔎 SEO-ready: metadata, hreflang, sitemap and structured data
- ♿ Accessible, responsive UI with a custom toast / dialog / loader UI kit

## 🛠 Tech Stack

| Layer | Technology |
|---|---|
| Framework | Next.js 16 (App Router, Turbopack) · React 19 |
| Language | TypeScript (strict) |
| Styling | Tailwind CSS v4 · MUI (dashboard widgets) |
| Data | Axios with auth & loader interceptors |
| Charts / Export | Recharts · xlsx |
